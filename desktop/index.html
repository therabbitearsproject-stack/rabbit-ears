Captions without extra setup

Existing show subtitles are used first. Bundled multilingual Whisper and local translation fill in when a show has no usable track; Windows Live Captions is optional on supported Windows 11 systems. Size and color apply to supplied tracks and local captions. Text already burned into the picture cannot be restyled. In Settings, App language changes the interface and subtitle language. Automatic uses your supported device language, then a broad country fallback; saved manual choices win. No Python installation, speech account or separate model download is needed.

Your TV, wherever you want it

Pop out keeps the themed TV bezel and transport in the same app window. Return restores the full app and its menus. The Audio window follows your chosen theme.

Updates

On Windows, choose Help → Check for app updates. Updates ask before downloading and restarting. On Mac and Linux, quit and install the new app or package. Internet is required for streams.
