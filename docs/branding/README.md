# Rabbit Ears branding backup

The current family uses true black/white artwork and a bunny skull integrated into the dash. SVG masters contain outlined lettering, have transparent backgrounds, and scale without pixelation.

- Full, compact, signature and square masters: ../../assets/brand/polished/
- Stacked R-E above .stream: stacked-dark.svg (white) and stacked-light.svg (black) in the same directory; matching transparent PNGs are 4096 pixels wide.
- All five options, dark and light: rabbit-ears-polished-comparison.png and .svg here.
- Stacked-only comparison: rabbit-ears-stacked-preview.png here.

Dark means white artwork for a dark background; light means black artwork for a light background. Background panels in comparison images are presentation aids; the master files are transparent.

The full skull family is live on the website and Discord server, banner, invite background, and Watch Party app/bot. The stacked option is an additional approved design option, not a replacement deployed to those surfaces.

Setup history, email routing, remaining account administration, and watch-party implementation notes are in ../plan.txt. Later entries supersede earlier statuses. Current operational setup is also documented in ../../community/README.md. Secrets remain outside Git.
